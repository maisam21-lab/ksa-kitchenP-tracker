Put your Google Cloud service account JSON key here and name it:

    credentials.json

So this folder should contain:

    scripts/credentials.json

The app uses it to read from BigQuery (Kitchen Master Data). Get the key from Google Cloud Console or your admin. Do not commit credentials.json to git (it is in .gitignore).

Then run (PowerShell), from the ksa-kitchenp-tracker folder:

    $env:GOOGLE_APPLICATION_CREDENTIALS = ".\scripts\credentials.json"
    streamlit run app/tracker_app.py

(Or use the full path to credentials.json if you run from a different folder.)
