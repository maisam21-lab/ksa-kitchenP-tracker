# Looker Studio — time comparison control (short labels)

Use these **display names** in the report control (rename options in Looker Studio; they are not deployed from this repo).

## Option labels (wordy → short)

| Old style (example) | New label |
|---------------------|-----------|
| Year to date · vs same calendar months last year | **YTD vs last year** |
| Table months · Auto (YoY if All months, else MoM) | **Auto compare** |
| Table months · vs previous month | **vs prior month** |
| Table months · vs same month last year | **vs year ago** |
| Table months · Custom (two dates) | **Custom range** |

## Optional caption (one line under the control)

All months in the table → compare to last year. Otherwise → compare to prior month.
